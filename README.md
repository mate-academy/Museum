A responsive museum landing page built to a Figma design with semantic HTML, modular SCSS, and minimal JavaScript. Sections
Tech stack and architecture

HTML5: semantic structure (header/nav/main/section/footer) with anchor navigation and accessible labels.

SCSS: modular architecture (variables, mixins, base, layout, components, blocks), BEM naming, single minified bundle, font-display: swap.

JavaScript: lightweight image slider; minimal class toggling on hover states only where needed; no heavy frameworks or global state.

DEMO: https://artemyakhno.github.io/Museum/
